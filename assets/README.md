# Property Studio AI Assets

This directory contains static assets and sample media used for video synthesis and testing.

## Directory Structure:
- `sample_images/`: Contains sample property images (1280x720) representing:
  - `01_exterior.jpg`: Modern building facade and architecture
  - `02_living_room.jpg`: Contemporary living lounge
  - `03_modular_kitchen.jpg`: Modular kitchen with granite countertop
  - `04_bedroom.jpg`: King-size master bedroom suite
  - `05_balcony_view.jpg`: Scenic balcony overlooking tree canopy and hills
- `audio/`: Directory for optional cached voiceovers or external audio tracks.
